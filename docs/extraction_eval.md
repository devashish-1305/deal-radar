## Setup
- Prompt: `prompts/extract_v1.md`, identical for both models. Input = target company name + article text.
- Models: `claude-haiku-5-5`, `claude-sonnet-5-5`; identical request parameters (system prompt, max_tokens 4000, no other settings).
- **Deviation from plan: temperature 0 was not used.** anthropic SDK 1.5.0 has no `temperature` parameter, and the API rejects it for both models (HTTP 400 "`temperature` is deprecated for this model", request ids req_011CgTBqjUpeW24NKpDqnNKU and req_011CgTBqqmr51D6nFzRpP7HG, 2026-10-27). API default settings were used, identical for both models. Consequences: outputs are not guaranteed deterministic (re-runs reuse the cached raw responses in `data/raw/llm/`, so this report is reproducible from the cache), and the API's default reasoning effort differs by model (per the Claude API reference: medium for Haiku 5.5, high for Sonnet 5.5).
- Scope: Evidence usable at the pair anchor after the content_leak exclusion. Undated, post-anchor and excluded items are never sent (enforced in `extract.extract_document`).
- Post-checks (deterministic, each rejection logged below): quote is a whitespace-normalised substring of the article text; subject_company names the target; signal_type belongs to signal_class; quote ≤ 25 words.
- publication_date and source_url always come from the Evidence record, never from the LLM.
- Matching: one-to-one on (evidence_id, signal_type). Further predictions of the same type in the same document are duplicates: reported separately, counted as neither TP nor FP.
- Pricing used for cost (USD per million tokens, input/output), **provisional** (list prices as cached in the Claude API reference on 2026-10-06, not invoice-verified): `claude-haiku-5-5` $0.10/$0.50; `claude-sonnet-5-5` $2.00/$10.00.

## Recommendation for Step 7

**Use `claude-sonnet-5-5` for Step 7.** On this sample it had higher precision (73% vs 65%) at slightly lower recall (89% vs 94%), no duplicates, and, most importantly, **no false direct-intent signal**: Haiku labelled advisers on a completed 2022 deal as `advisers_appointed`, exactly the error that would most inflate a company's score. Sonnet's two misses are a type confusion shared with Haiku (chair → governance_change) and one quote correctly rejected by the 25-word check. Both models share the remaining false positives (`recently_acquired` double-labels of sponsor deals, sector-context sentences, an advisory board), which are consistent and can be handled deterministically in Step 7. Cost is not a deciding factor at pilot scale (~$0.13 vs ~$0.01 for 16 documents); Haiku (~13× cheaper per run here) is the candidate to re-test at 100k-company scale with a stricter prompt. With 16 documents these differences are a handful of signals each: illustrative, not significant.
